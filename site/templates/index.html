Install IceDash

One command over SSH. After that, IceDash updates itself from its own menu.

  • ZimaOS 1.8.0+ · amd64
  • CasaOS 0.4.15+ · amd64, arm64

ZimaOS

Installs as a ZimaOS module, beside the stock dashboard

http://<your-server>/modules/icedash/
  1. Open a terminal on your ZimaOS box (SSH, or the Terminal in Settings).
  2. Run the commands on the right. They download IceDash, check it and install it.
  3. Open the IceDash tile on the ZimaOS dashboard, or the address above.
  4. Sign in with your ZimaOS account. There is nothing else to set up.
{{icon:info}}Want IceDash at http://<your-server>/? Turn on Settings → General → Open IceDash at this server's address. The ZimaOS dashboard stays at /index.html
user@zimaos: /tmp 
user@zimaos:~$ cd /tmp
curl -fsSLO {{repo}}/releases/latest/download/icedash-amd64.raw
curl -fsSLO {{repo}}/releases/latest/download/icedash-amd64.raw.sha256
sha256sum -c icedash-amd64.raw.sha256
mv icedash-amd64.raw icedash.raw
sudo zpkg install /tmp/icedash.raw
user@zimaos:/tmp$
To remove it
  • Run sudo icedash --uninstall, then sudo zpkg remove icedash.
  • Settings and notifications stay in /DATA/.icedash until you delete that folder.

CasaOS

Becomes the main page, with the stock UI one click away

http://<your-server>/
  1. Open a terminal on your CasaOS box over SSH.
  2. Run the command on the right. Running it again repairs or reinstalls IceDash.
  3. Open your server's address. IceDash is the main page now.
  4. Sign in with your CasaOS account.
{{icon:info}}The stock CasaOS UI stays at http://<your-server>/casaos/, and IceDash links to it from its menu
user@casaos: ~ 
user@casaos:~$ wget -qO- {{repo}}/releases/latest/download/install-casaos.sh | sudo sh
user@casaos:~$
To remove it
  • sudo /opt/icedash/current/uninstall.sh puts the stock CasaOS UI back at the main address.
  • Add --purge to delete IceDash's settings too. Apps you installed from IceDash stay in CasaOS either way.

Good to know

The questions people ask before they install it.

Does it change ZimaOS or CasaOS?
No system files change. On ZimaOS IceDash is a module beside the stock dashboard. On CasaOS it takes the main address and keeps the stock UI at /casaos/; the uninstall script gives the address back. Apps installed from IceDash are normal apps of your system.
How does it update?
IceDash checks for new versions and shows Update now in its menu. If an update fails to start, the previous version comes back by itself. An admin can also let it install updates at night, between 02:00 and 05:00.
Who can do what?
You sign in with your ZimaOS or CasaOS account. Admins get everything. Members get their own look, dock and notifications and can open apps, but not Files, the Terminal, credentials or app actions.
Are mods safe?
Themes are colours and CSS only. Each widget runs in its own sandbox, never sees your sign-in, and shows the permissions it asks for before you turn it on.
Is it free?
Yes. IceDash is free and open source, and so is IceStore, the app store inside it.
